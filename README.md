# Homebrew tap for Kuana

```sh
brew install --cask berkayakin/tap/kuana
```

[Kuana](https://github.com/berkayakin/kuana-editor) is a fast, GPU-rendered code editor.
`Casks/kuana.rb` is updated by Kuana's release workflow from
[`scripts/kuana.rb`](https://github.com/berkayakin/kuana-editor/blob/main/scripts/kuana.rb); change it there.
